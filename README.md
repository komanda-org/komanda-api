# Komanda API

Backend service built with [NestJS](https://nestjs.com) and TypeScript.

## Getting Started

### Prerequisites

- Node.js 20.x LTS or higher
- npm

### Installation

```bash
npm install
```

### Running the Application

```bash
# Development mode (with watch)
npm run start:dev

# Production mode
npm run start:prod

# Standard start
npm run start
```

The application runs on **port 3000** by default.

## Testing

```bash
# Unit tests
npm run test

# E2E tests
npm run test:e2e

# Test coverage
npm run test:cov
```
